# Конспекты — Telegram Mini App v7

Статическое учебное приложение для GitHub Pages и Telegram Mini Apps.

## Что внутри

- Главная → предмет → лекции → чтение.
- Квиз по отдельной лекции и по всей дисциплине.
- Раздел «Сессия» со статусами «не начинал / учу / знаю», поиском и тренировкой.
- «Материалы» с исходными PDF/DOC/DOCX.
- Английский: Vocabulary Units 1–4, вопросы Units 1–3, лекция и исходный DOCX.
- 12 цветовых палитр × светлый/тёмный режим, 8 стеков шрифтов, размер текста, интервал и ширина чтения.
- Миграция старого localStorage `konsp-mini-v1` в `konsp-mini-v2`.
- Premium UI/Motion: интерактивный desktop-sidebar, Focus Mode для чтения лекций, page transitions, микроанимации карточек и квизов.

## Математика

MathJax 3 подключается один раз и запускается вручную после вставки контента. В `app.js` есть нормализация старого LaTeX и текстовый fallback на случай, если CDN MathJax недоступен. Формулы и таблицы прокручиваются по горизонтали внутри своего блока и не расширяют страницу.

## Обновление GitHub Pages

1. Открой репозиторий `groxek/tgminiapp`.
2. В корне репозитория замени **полностью** четыре файла: `index.html`, `styles.css`, `app.js`, `data.js` файлами из этой сборки.
3. Папку `materials/` замени целиком папкой `materials/` из этой сборки. Не переименовывай файлы внутри: пути уже прописаны в `data.js`.
4. Убедись, что в корне репозитория рядом лежат `index.html`, `styles.css`, `app.js`, `data.js`, а папка `materials/` содержит 8 файлов из списка выше.
5. Сделай Commit изменений в ту же ветку, из которой публикуется GitHub Pages.
6. Открой **Settings → Pages** и проверь, что публикация по-прежнему идёт из этой ветки/корня. Менять настройки Pages не нужно, если они уже работали.
7. Дождись завершения GitHub Pages deployment и открой `https://groxek.github.io/tgminiapp/` в обычном браузере: проверь Главную, одну лекцию, квиз, «Сессию», «Материалы» и «Настройки».
8. После этого открой тот же Mini App из Telegram. **URL Telegram Mini App менять не нужно.**

## Быстрая проверка после публикации

- В консоли браузера нет ошибок загрузки `app.js`, `data.js`, `styles.css`.
- В математических лекциях не видны сырые `\\begin{pmatrix}`, `\\frac`, `\\lim` и другие команды LaTeX.
- Кнопка «Показать ответ» не показывает hint вместо ответа.
- Статусы вопросов сессии сохраняются после перезагрузки.
- Старая отметка прогресса из v1 не пропала после первого запуска v7.
- На ширине от 1024 px видна боковая панель, на телефоне — нижняя навигация.


## Что изменилось в v7

- Список предметов в desktop-sidebar стал полноценной навигацией с `hover`, `active` и `aria-current`.
- На экране лекции добавлен «Режим фокуса»: sidebar/topbar скрываются, чтение центрируется, выход доступен отдельной кнопкой и по `Esc`; Telegram BackButton сначала выводит из Focus Mode.
- Добавлены мягкие page transitions, физичные hover-состояния, glow/shadow-слои и адаптивный motion с поддержкой `prefers-reduced-motion`.
- Квиз получил анимированное заполнение progress bar и отдельную анимацию появления подтверждённого ответа.
- Визуальная система обновлена без изменения структуры данных, маршрутов и URL Telegram Mini App.
