# Конспекты — Telegram Mini App v8

Учебное приложение для Telegram (и обычного браузера): лекции, квизы, вопросы к сессии с ответами, исходные материалы. Статический сайт на GitHub Pages, без сборки и без зависимостей.

**Контент живёт в Markdown**: папка [`content/`](content) — одна подпапка на предмет, один `.md` на лекцию. Новая лекция не требует изменений кода: GitHub Pages (Jekyll) при каждом деплое генерирует `content/manifest.json` со списком файлов, приложение само находит, скачивает и отрисовывает их. Как писать лекции — [`content/README.md`](content/README.md).

## Возможности

- Главная с готовностью к сессии, «Продолжить чтение», предметы и экзамены.
- Читалка: оглавление (сбоку на широком экране), прогресс чтения и продолжение с места, Режим фокуса (`F`, выход — `Esc` или кнопка «Назад» Telegram), размер шрифта на лету.
- Формулы: MathJax 4 с автоматическим переносом длинных формул; остаток прокручивается внутри блока — страница никогда не шире экрана. Ленивая отрисовка по мере прокрутки.
- Выноски `> [!TIP]`, таблицы с горизонтальной прокруткой, блок-схемы Mermaid, копирование кода.
- Квиз-движок: карточки «Показать ответ → Знаю / Не знаю», незнакомые возвращаются через несколько карточек, отмена ответа, продолжение прерванной сессии, режимы «все / незнакомые / 10 случайных», итог с повтором ошибок. Клавиши: `Space` — показать, `1`/`←` — не знаю, `2`/`→` — знаю, `Z` — отменить.
- Сессия: 653 вопроса к экзаменам с ответами (история, МЛиТА, английский, линейная алгебра, матанализ + задачник), статусы «Не начинал / Учу / Знаю», фильтры, поиск.
- Полнотекстовый поиск по лекциям, вопросам и файлам.
- 12 палитр + «Telegram» (подстраивается под тему клиента), светлая/тёмная тема, 8 шрифтов, интервал и ширина текста, экспорт/импорт прогресса.
- Telegram WebApp: safe areas и fullscreen, цвет шапки/фона/нижней панели под тему, BackButton и SettingsButton, тактильный отклик, отключение закрытия свайпом при чтении, нативные подтверждения.
- Прогресс v7 (`konsp-mini-v2`/`v1`) переносится автоматически; старые ссылки `#/lecture/…`, `#/session/…` перенаправляются.

## Структура

```text
index.html                 оболочка: sidebar, top bar, экран, tab bar
_config.yml                настройки Jekyll для GitHub Pages
assets/
  css/                     tokens → base → layout → components → reader → quiz
  js/
    main.js, app.js        запуск, роутинг экранов, переходы, общие действия
    core/                  dom, router, store (+миграция), telegram, theme, storage, legacy
    content/               catalog (манифест, кэш), markdown (marked + формулы/выноски/вопросы),
                           sanitize, render, math (MathJax), diagrams (Mermaid), search, plaintext
    quiz/engine.js         чистый движок квиз-сессий
    ui/                    иконки, компоненты, тосты, режим фокуса
    views/                 home, subject, lecture, exam, question, quiz, session, materials, search, settings
  vendor/marked.esm.js     Markdown-парсер (MIT), вшит — ядро не зависит от CDN
content/                   предметы, лекции, exam.md, materials/, manifest.json (шаблон Jekyll)
tools/
  serve.mjs                локальный сервер + манифест «как на Pages»
  check-content.mjs        проверка всех Markdown-файлов парсером приложения
```

С CDN грузятся только MathJax (когда на экране есть формулы) и Mermaid (когда есть схема); без них формулы показываются как TeX, схемы — как текст.

## Локальный запуск

Нужен Node.js 18+.

```bash
node tools/serve.mjs          # http://localhost:4173/
node tools/check-content.mjs  # проверка контента
```

`?qa` в адресе включает `window.__KONSP_QA__` (состояние, маршрут, каталог) для автотестов.

## Публикация

GitHub Pages: **Settings → Pages → Deploy from a branch**, ветка с приложением, папка `/ (root)`. Jekyll должен оставаться включённым (не добавляйте `.nojekyll`): он собирает `content/manifest.json`. Если манифест недоступен, приложение на `*.github.io` берёт список файлов из GitHub API.

После пуша дождитесь завершения «pages build and deployment» и откройте сайт; URL Mini App в @BotFather менять не нужно.

## Хранение данных

Прогресс и настройки — `localStorage` (`konsp-v3`) на устройстве пользователя; кэш метаданных лекций — `konsp-meta-v1`. Перенос между устройствами — «Настройки → Экспорт/Импорт».
