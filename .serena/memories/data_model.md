# Контент и прогресс

## Файлы (`content/`)
- `content/<subject>/` — предмет; имя папки = id предмета в URL и ключах. Файлы и папки с `_` или `.` в начале не публикуются (черновики).
- `subject.json` (необязателен): `title`, `short`, `icon`, `accent` (id из `.accent-*` в `tokens.css`), `order`, `description`, `exams{<slug>:{kind,title}}`, `materials{<filename>:{title,description,order}}`.
- Лекции: любые `.md`, кроме `exam*.md` и `README/index.md`, в том числе в подпапках (подпапка = группа). Имя `NN-slug.md`: `NN` — порядок, slug — ключ (`<subject>/<slug>`).
- `exam*.md` в корне предмета — списки вопросов. `materials/**` — файлы раздела «Файлы».
- Метаданные без YAML: комментарий `<!-- meta\nkey: value\n-->` в начале файла (`title`, `order`).
- `content/manifest.json` — Liquid-шаблон, не данные. Руководство для авторов — `content/README.md`, GitHub показывает его в папке.

## Разметка (`assets/js/content/markdown.js`)
- `# Заголовок` — название документа. Первый абзац или цитата после него — lead.
- Формулы: `$…$` (правило pandoc: без пробела внутри у `$`, после закрывающего `$` не цифра), `$$…$$`, `\(…\)`, `\[…\]`. Токенизируются до разбора Markdown, поэтому `\{`, `\\`, `_` внутри формул безопасны. В таблицах `|` внутри формулы режет ячейку — нужен `\lvert … \rvert` или `\|`.
- Выноски: `> [!TYPE] заголовок`, свёрнутые — `[!TYPE]-` и `[!TYPE]+`. ```` ```mermaid ```` — блок-схемы.
- Квиз лекции: раздел `## Вопросы для самопроверки` (регулярка `QUIZ_HEADING`); каждый `###` — карточка. id карточки = slug заголовка вопроса (`createSlugger(48)`).
- Экзамен: вопрос — заголовок уровня 2 и глубже, начинающийся с числа (`## 12. …`). Заголовки без числа — группы. Ответ идёт до заголовка того же или более высокого уровня. Цитата `>` сразу после заголовка вопроса — его условие. id = номер; при повторе номера — `N-2`.

## Ключи прогресса (не ломать)
- Прочитанное: `reading['<subject>/<lectureSlug>']`.
- Карточки: `cards['<subject>/<docSlug>#<qid>']` = `{s: new|learning|know, n, ok, ko, streak, at}` — общие для вопросов экзаменов и квизов.
- Поэтому нельзя переименовывать папки предметов, slug лекций и `exam*.md`, нельзя перенумеровывать вопросы экзаменов, а заголовки вопросов квиза правьте с осторожностью.
- Миграция из v7 — через карты `core/legacy.js`, где `QUIZ` сгенерирован скриптом миграции.
