# Task completion

1. `node --check` для изменённых JS; `node tools/check-content.mjs` после любых правок в `content/` или в `assets/js/content/markdown.js`.
2. Прогон в браузере через `tools/serve.mjs` на 390×844 и 1440×900, тёмная и светлая тема. В консоли не должно быть ошибок и 404. Проверить:
   - формулы отрисованы, горизонтальной прокрутки страницы нет (`scrollWidth === innerWidth`);
   - Mermaid отрисован;
   - квиз: показать → знаю / не знаю → незнакомая карточка вернулась, отмена работает;
   - фокус-режим и Esc;
   - поиск находит, фильтры экзамена работают;
   - миграция: подложить старый `konsp-mini-v2` → прогресс переехал.
3. Новые классы в шаблонах должны иметь CSS: аудит «класс из JS без правила в `assets/css`».
4. Не коммитить служебное (`.serena/`, `.vscode/`, скриншоты QA). Push в `main` — только по просьбе пользователя (это деплой).
